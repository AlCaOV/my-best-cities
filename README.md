# Мої 3 найкращі міста світу

Статичний web-блог про три міста: Афіни, Київ і Варшаву.
Лабораторна робота №1 з дисципліни «WEB-програмування».

Автор: Середній Юрій Олегович, група КН-42.

## Структура проєкту

```
my-best-cities/
├── index.html         — головна сторінка
├── city-athens.html   — сторінка про Афіни
├── city-kyiv.html     — сторінка про Київ
├── city-warsaw.html   — сторінка про Варшаву
├── form.html          — форма «Запропонувати місто»
├── images/            — фотографії міст
└── README.md          — опис проєкту
```

## Технології

HTML5 (семантична розмітка), Git, GitHub, GitHub Pages.
